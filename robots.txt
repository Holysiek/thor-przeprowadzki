# THOR Przeprowadzki — strona

Statyczna strona (HTML/CSS), gotowa do wrzucenia na **Netlify przez GitHub**.
Formularz kontaktowy używa **Netlify Forms** i działa tylko po wdrożeniu przez repo Git
(przy zwykłym przeciąganiu folderu formularze często się nie podłączają — dlatego idziemy przez GitHub).

## Pliki
- `index.html` — strona główna (Przeprowadzki Zielona Góra)
- `uslugi.html`, `przeprowadzki-studenckie.html`, `galeria.html`, `kontakt.html`
- `dziekujemy.html` — strona po wysłaniu formularza
- `img/` — zdjęcia
- `sitemap.xml`, `robots.txt`, `netlify.toml`

## Jak wdrożyć (krok po kroku)
1. Załóż konto na https://github.com i utwórz nowe, puste repozytorium (np. `thor-strona`).
2. Wgraj do repozytorium **całą zawartość tego folderu** (Add file → Upload files → przeciągnij pliki i folder `img` → Commit).
3. Wejdź na https://app.netlify.com → **Add new site → Import an existing project → GitHub** i wskaż to repo.
4. Ustawienia builda zostaw puste (publish directory: `.`), kliknij **Deploy**.
5. Po wdrożeniu w panelu Netlify zakładka **Forms** pokaże formularz „kontakt". 
   W **Forms → Settings → Form notifications** dodaj powiadomienie e-mail na: holysmarcel@gmail.com.
6. Podłącz domenę `thor-przeprowadzki.pl` w **Domain settings** (Netlify poda, co ustawić u rejestratora domeny).

## Po wdrożeniu — WAŻNE dla SEO
- W Google Search Console wgraj/odśwież `sitemap.xml` i kliknij **Sprawdź URL → Poproś o zaindeksowanie** dla każdej podstrony.
- Zadbaj o spójność danych (nazwa „THOR Przeprowadzki", telefon 576 407 870) na stronie i w wizytówce Google — to mocny sygnał lokalny.
- Zbieraj opinie: przycisk „Wystaw opinię" na stronie prowadzi prosto do okna oceny w Google.
- Linki do Google i godziny otwarcia (pon–sob 07–23, niedz 08–20) są już wpisane w kod.
